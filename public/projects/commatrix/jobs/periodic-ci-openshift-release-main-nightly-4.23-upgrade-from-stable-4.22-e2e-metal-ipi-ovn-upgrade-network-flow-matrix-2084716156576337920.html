• Root Cause: The baremetalds-devscripts-setup CI pre-step runs 01_install_requirements.sh, which installs a version of the argcomplete Python package that uses PEP 604 union type syntax (str | bytes) in type annotations. This syntax requires Python ≥3.10, but the CI runner uses Python 3.9, causing an import-time TypeError that crashes ansible-galaxy and fails make requirements. Because the setup script exits 2 before the OCP cluster is installed, no kubeconfig is generated and all downstream errors (/root/dev-scripts/ocp/ not found, INVALID_ZONE: libvirt) are pure cascades. The commatrix project tests never ran.
• Breaking PR/Commit: Unknown — this is a transitive dependency version bump in argcomplete upstream or in the dev-scripts pinned requirements, not in commatrix code.
• Flake? No — deterministic import-time crash; will reproduce on every run until the package pin or Python version is fixed.
• Fix: Pin argcomplete to a version compatible with Python 3.9 (e.g., argcomplete<3.0) in dev-scripts requirements, or upgrade the CI runner base image to Python 3.10+.
