Root Cause Groups


Group A — Namespace Terminating Race Condition (1 failure)

• Tests: e2e-telco5g-ptp-telco5g-ptp-tests
• Classification: infra_issue | Confidence: high
• Evidence:

```

Error from server (Forbidden): error when creating "STDIN": roles.rbac.authorization.k8s.io "privileged-rights" is forbidden: unable to create new content in namespace openshift-ptp because it is being terminated

Error from server (Forbidden): error when creating "STDIN": rolebindings.rbac.authorization.k8s.io "privileged-rights" is forbidden: unable to create new content in namespace openshift-ptp because it is being terminated

Error from server (Forbidden): error when creating "STDIN": pods "podman" is forbidden: unable to create new content in namespace openshift-ptp because it is being terminated

```

• Root Cause: The test script deletes the openshift-ptp namespace at the start (oc delete namespace openshift-ptp) and immediately tries to recreate resources into it. The namespace was still in Terminating state when the oc apply -f - was issued, preventing any new resource creation. The script does not wait for full deletion before proceeding.
• Breaking PR/Commit: Unknown — this is an infrastructure/timing race, not a code regression. No relevant commits in the provided git log.
• Flake? yes — transient timing race; the deletion of openshift-ptp from a prior run or the same run's setup phase did not complete before the next create attempt.
• Fix: Add a wait loop after oc delete namespace openshift-ptp to confirm the namespace is fully gone before proceeding (e.g., oc wait --for=delete namespace/openshift-ptp --timeout=300s).
